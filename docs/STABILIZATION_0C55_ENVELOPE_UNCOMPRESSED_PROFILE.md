# FreeLocalPlayer — 0-C.5.5: несжатый журнал, экранирование JSON и AtomicFile

## Основание

На Motorola Edge 60 Pro (20.11.2026, 20:38) измерено шесть профилей этапа 0-C.5.3. Экспериментальный GZIP замедлил запись во всех размерах/профилях. На 20 000 треков исходный `stage()` p50 составлял 216,143 мс при повторяющихся данных и 255,443 мс при разнообразных; `JSONObject`-обёртка в экспериментальном пути — 193,135/226,504 мс p50. Но измерение атомарной записи было сделано **для сжатых байтов**, что не позволяет утверждать, будто весь остаток времени — только сериализация. Источник: `docs/STABILIZATION_0C53_JOURNAL_DEEP_PROFILE.md`.

## Цель 0-C.5.5

Независимо, на синтетических снимках библиотеки из 630/5000/20000 треков с повторяющимися и разнообразными данными, сопоставить три пути:

1. действующий `LibraryPendingWriteJournal.stage()` с его реальным `AtomicFile`, без изменений;
2. прежнее формирование v1 через `JSONObject().put(...).toString()` с **несжатой** записью в отдельный `AtomicFile`;
3. альтернативную запись **такой же логической v1-обёртки** через `StringBuilder`, корректно экранируя кавычки, обратные слеши, `\b`, `\f`, `\t`, `\n`, `\r`, символы U+0000..001F и U+2028/U+2029, без GZIP, со своим QA-`AtomicFile`.

Тест считает p50/p95 общего времени и отдельных hash/encode/atomic для двух экспериментальных вариантов, p50/p95 исходного `stage()`. Каждый профиль: **16 повторов, 3 прогрева**, порядок трёх методов чередуется. Сравниваются содержимое после записи, поля, исходный и целевой SHA-256, равенство `desiredJson`. Замеры не включают стоимость полного кодирования исходной `LibraryState` в JSON, UI и Room.

## Девять Android-тестов

- 6 профильных: `repetitive/varied × 630/5000/20000`;
- 1 тест спецсимволов и Unicode: кавычки, `\`, переносы и управляющие коды, U+2028/U+2029, акцентированные символы, китайские и emoji;
- 1 тест чтения нового кандидата **без изменения рабочего кода** через существующий `LibraryPendingWriteJournal.recover`: восстановление после прерванного commit, ровно один replay, удаление журнала, повторный запуск `NONE`;
- 1 тест конфликта с более новым каноническим JSON: возврат отказа и сохранение обеих версий.

## Неизменные ограничения

**Никаких обновлений основного APK**, переноса Room-primary, смены версии журнала, запись в `local_library_v1`, удаления данных или операций над реальными медиа. Все файлы и предпочтения тестов имеют случайные имена `__flp_0c55_*` в приватной директории приложения. Повторное сохранение канонического XML запрещено; установщик сравнивает SHA-256 до/после на физической Motorola Edge 60 Pro. Устанавливается только `app-debug-androidTest.apk`, после предварительной проверки подписи всех APK.

Производственный код `LibraryPendingWriteJournal.kt`, `PendingLibraryRecoveryPolicy.kt`, `LibraryStore.kt`, AndroidManifest и подписанный основной APK **не меняются**. Перед публикацией разрешены только файл теста и данный документ. При неуспехе скрипт удаляет только новые файлы со строго ожидаемыми контрольными суммами, не делает reset, rebase, uninstall или `pm clear`.
