# FreeLocalPlayer — 0-C.3-C: временное чтение Room и автоматический возврат к JSON

**Статус пакета:** подготовлен. До фактического отчёта Gradle/Android нельзя объявлять этап пройденным.

## Цель

На Motorola Edge 60 Pro проверить не только чистый `VerifiedRoomReadSelector`, но и фактическую работу `MainActivity → LibraryStore.load()` после холодного запуска, когда Room-read включён, а затем — обратное переключение на JSON. **Это ещё не Room-primary**: каноническая запись и восстановление всегда остаются через `local_library_v1` (SharedPreferences JSON); Room сохраняет роль синхронизируемого зеркала. Пользовательские UUID, тексты, позиции плейлистов, MIDI, SAF-права, schema Room, package и версия APK не меняются патчем.

## Защита на физическом телефоне

- Безопасное временное включение: одновременно `room_verified_read_0c3b=true` и `room_verified_read_expires_0c3c_ms=<unix time ms>`; максимальное будущее окно — **180 секунд**. Если флаг отсутствует, срок отсутствует, неверного типа, истёк или находится дальше 180 секунд — выбирается JSON, и попытка активного флага сбрасывается.
- `LibraryStore.load()` **вначале парсит JSON**; затем, только при действующем окне, читает Room одной транзакцией и сравнивает полные данные, штамп и SHA-256. Несовпадение/SQLite failure => `ROOM_READ_JSON_FALLBACK` и немедленное отключение временного флага.
- Флаг меняется только через Android instrumented QA (`TemporaryRoomReadRolloutDeviceTest`); тест не удаляет пользовательские файлы и не редактирует медиатеку. Если ADB пропадёт, срок сам истечёт и следующая загрузка выберет JSON. Если процесс не запускается, флаг может физически остаться в prefs до следующей загрузки, но после истечения срока является недействительным.
- Телефонный скрипт сначала подтверждает **ровно одно** физическое Motorola Edge 60 Pro, Git HEAD и хеши исходников, существующий проверенный ZIP (628 / 3 / 8) и подпись установленного / нового / тестового APK. Архив из 14 ноября может быть **устаревшим**; его наличие не означает сохранность последних правок. Перед `-Mode Run` рекомендуется создать *свежий* пользовательский SAF ZIP и сохранить его за пределами телефона.
- ADB `install -r` без `uninstall` и `pm clear`; холодный запуск намеренно выполняет `am force-stop`, поэтому перед QA **остановить воспроизведение** и закончить ручные правки. Никаких нагрузочных 5000/20000 на телефоне.
- На успех обязаны пройти `ROOM_READ_VERIFIED` от настоящего `LibraryStore.load()` после холодного старта, сохранность SHA-256 канонического JSON до/после, отключение флага, следующий холодный старт с `ROOM_READ_JSON_DEFAULT`. Тест по завершении выключает флаг даже если проверка упала, пока телефон доступен.

## Что не доказывает стадия

- Нет бесконечного Room-only режима: ограниченный экспериментальный флаг сбрасывается. Не подтверждает безопасный отказ при потере питания во время записи SQLite либо всю долговременную стратегию миграции.
- Контрольный SHA сравнивает **только JSON медиатеки**, а не отдельные бинарные данные MIDI/аккордов и иные настройки. Сохранность последних требует отдельного SAF ZIP проверки.
- Счётчики/производительность 5000 и 20000 пока не измеряются на Motorola. При желании тестировать нагрузку — выделенное тестовое устройство/изолированные in-memory DB.

## Как применять

1. Скачать `FreeLocalPlayer_0C3C_RoomRead_Lease_QA.zip` в Downloads. Установщик `Apply-FreeLocalPlayer-RoomLease-0C3C.ps1 -VerifyOnly` сверяет Git и входные SHA-256, ничего не меняя.
2. Выполнить установщик без `-VerifyOnly`: резервные копии только в `.patch-backups`, Android Gradle build + unit + instrumentation APK, Git commit/push после PASS. При любой ошибке до коммита возвращается исходный код, без force push, без соседних каталогов.
3. Подключить Motorola по USB, остановить воспроизведение и ручное редактирование, сохранить свежий ZIP вне телефона.
4. Запустить `tools/Verify-FreeLocalPlayer-PhoneRoomLease-0C3C.ps1 -Mode Audit -ProjectPath <project>`; после успешной диагностики — `-Mode Run`. Отчёты в `.patch-backups/room-rollout-lease-phone-qa-*`.
5. Если сеанс прервался или USB пропал, после переподключения `-Mode Recover` отключит флаг без установки, после чего можно продолжать пользоваться плеером. Если телефон недоступен, **спустя 180 секунд после активации** следующая загрузка гарантированно не использует истёкший временный флаг (при штатных системных часах).

## Критерии приёмки

`GRADLE_BUILD_AND_TESTS=PASS`, `ROOM_SCHEMA_V1_EXPORTED=PASS`, `GITHUB_PUSH=PASS`, `APK_SIGNING_CERT_MATCH=PASS`, `REAL_ROOM_COLD_START=PASS`, `COLD_START_PASS=json_after_revoke`, `CANONICAL_CATALOG_SHA256_UNCHANGED=PASS`, `RESULT=SUCCESS ROOM_ROLLOUT_COLD_START_AND_REVOKE_PASS`.

Не считать этап принятым только по модульным тестам или успешному обновлению APK.
