# FreeLocalPlayer — этап 0-C.5.4: независимая матрица отказов журнала

## Основание и цель

На реальной Motorola в этапе 0-C.5.2 измерена стоимость `stage()` — 8.957/57.657/220.003 мс p50 для 630/5000/20000 синтетических треков. Код профиля 0-C.5.3 с экспериментальным GZIP опубликован в GitHub (`02d6c63ad84e31c00d0ca78d4b0bee9717827426`), но численные результаты `DEEP_STAGE_RESULT` пока не внесены в репозиторий. Поэтому ускорение, сжатие или смена формата рабочего журнала **не применяются**.

Этот этап — отдельная инструментальная матрица отказов **существующего** `LibraryPendingWriteJournal`. Она необходима как защита от регрессий при последующей оптимизации.

## Матрица из 11 Android-тестов

1. Подменённый SHA-256 желаемого JSON: отказ, исходный каталог и журнал сохранены.
2. Некорректный формат SHA-256 исходной версии: отказ, состояние сохранено.
3. Неподдерживаемая версия формата журнала: отказ.
4. Усечённый JSON журнала: отказ.
5. Валидный журнал + отказ строгой валидации: commit не вызывается.
6. Ошибка синхронного `SharedPreferences.commit()` на восстановлении: сохранение журнала, успешное восстановление после повторного открытия.
7. Конфликт с новым каноническим каталогом: fail-closed, оба состояния сохранены.
8. Семантически равный JSON с отличающимися байтами: конфликт, автоматического перезаписывания нет.
9. Сбой отдельной атомарной замены в **QA-файле** с `AtomicFile.failWrite()`: исходная запись пригодна для восстановления.
10. Журнал уже отражён в каноническом JSON: при холодном открытии не происходит повторного commit; журнал очищается; следующий запуск `NONE`.
11. Отсутствующий ключ предпочтений и существующая пустая строка различаются: при пустом значении конфликт, при полном отсутствии допустимо восстановление.

## Строгое разграничение окружений

- Тест создаёт только случайный каталог `filesDir/__flp_0c54_failure_matrix_*` и отдельные `SharedPreferences(__flp_0c54_preferences_*)`.
- Тест **не** читает, не удаляет и не изменяет `local_library_v1`, `LibraryStore`, Room, оригинальные медиафайлы, тексты и плейлисты пользователя.
- В основной APK новые файлы не вносятся, его переустановка не производится; обновляется **только тестовый APK**.
- Перед/после теста сравнивается SHA-256 действующего `shared_prefs/local_library_v1.xml`, подтверждается неизменность base APK и совпадение сертификатов.
- Никаких `pm clear`, `adb uninstall`, `git reset --hard`, тестов на эмуляторе и имитаций аварии действующего процесса FreeLocalPlayer.
- Авария записи тестируется через `AtomicFile.failWrite()` в тестовом каталоге. Это **не** полная симуляция принудительного выключения питания или убийства процесса Android.

## Ограничения

Этот набор не измеряет ускорение, не подтверждает производительность GZIP и не доказывает восстановление после реального сбоя питания. Он проверяет, что текущие защитные свойства работают на физическом телефоне в детерминированных QA-сценариях. Данные 0-C.5.3 остаются необходимыми для выбора алгоритма следующего релиза.
