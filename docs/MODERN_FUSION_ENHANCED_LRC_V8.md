# FreeLocalPlayer — Modern Fusion v8: точная настройка времени слов Enhanced LRC

**Единая дорожная карта:** [PROJECT_ROADMAP.md](PROJECT_ROADMAP.md). **Трекер дизайна:** [GitHub #1](https://github.com/OlegRakhimov/MyPlayer/issues/1).

## Реализовано в исходниках v8

- В существующем экране «Текст + аккорды» открой **«Метки»** и на строке с настоящими метками слов нажми **«Настроить слова»**.
- В диалоге можно выбрать конкретное размеченное слово и сдвинуть его маркер на ±0,1 или ±0,5 секунды либо использовать текущую позицию песни.
- **Редактируется только существующая метка `<mm:ss.xxx>` выбранного слова.** Начало строки, остальные метки и аккорды не изменяются, сами слова не распознаются из звука.
- Действуют ограничения на временной порядок слов, начало/конец строки, длительность композиции; отрицательное время запрещено.
- Для одной физической строки с несколькими стартовыми метками LRC редактор слов отключён: слова общие у повторов, поэтому автоматическая корректировка была бы неоднозначной.
- Сохранение происходит **только** по нажатию «Сохранить»; «Отмена» и закрытие диалога не меняют текст.
- Обычные TXT и LRC, редактор времени строк v7, MIDI, A–B, Media3 и анализ аккордов не меняются. Исправления держатся в существующем локальном хранилище по прежнему обратному вызову `onSaveTimedLyrics`.
- Метаданные и формат перевода строк (CRLF/LF) сохраняются. Для редактируемого тега при необходимости добавляется точность долей секунды, без изменения других тегов.

## Проверка на телефоне

1. Открой песню с Enhanced LRC (метки `<...>` у отдельных слов), затем «Текст + аккорды» → «Метки» → «Настроить слова».
2. Выбери слово, смести на +0,1 с, нажми «Сохранить». Убедись, что изменилась только подсветка этого слова, соседние слова и аккорды остались синхронны.
3. Повтори с «Отмена». Убедись, что результат не сохраняется.
4. Проверь стандартный TXT, LRC, регулировку времени строк из v7, «Авто» прокрутку, MIDI и A–B.
5. Перезапусти приложение, удостоверься, что поправка сохранилась; проверь плейлисты и медиатеку после установки поверх предыдущей APK.
