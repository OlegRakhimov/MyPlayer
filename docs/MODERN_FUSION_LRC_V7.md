# Modern Fusion v7 — точная подстройка готового LRC

**Единый план:** [PROJECT_ROADMAP.md](PROJECT_ROADMAP.md). **Дизайн-трекер:** [GitHub issue #1](https://github.com/OlegRakhimov/MyPlayer/issues/1).

## Функции

- На экране «Текст + аккорды» для уже синхронизированного LRC/Enhanced LRC появилась кнопка **«Метки»**. Она включает режим правки времени и временно выключает автопрокрутку списка. Обычное нажатие на строку по-прежнему перематывает песню, когда режим выключен.
- При включённом режиме нажатие строки открывает диалог **«Время строки LRC»**. Можно сдвигать только выбранную строку с шагом **±0,1 с / ±0,5 с**, привязать время к текущей позиции воспроизведения и сохранить или отменить.
- Изменения **не применяются до «Сохранить»**. Выход или отмена не меняют медиа, плейлисты, MIDI, аккорды, скорость и LRC.
- Сохраняются исходный порядок строк в файле, метаданные, окончания строк, текст, неизменённые временные метки и оригинальные форматирующие символы.
- Для Enhanced LRC все пословные метки той же строки сдвигаются на величину сдвига начала строки — караоке остаётся согласованным. Если несколько стартовых меток разделяют общие метки слов, автоматическая правка блокируется с объяснением; пользователь может изменить такой нестандартный формат вручную.
- Запрещён переход изменяемой строки за соседние по времени строки, отрицательные значения, выход за длительность (если она известна), сдвиг меток слов в отрицательное время.
- Исходный LRC-парсер не модифицирован; не выполняется распознавание слов на слух и не выдумываются временные метки.

## Проверка

1. Сборка: `gradlew.bat :app:assembleDebug :app:testDebugUnitTest --no-daemon`.
2. На телефоне открой обычный LRC → «Метки» → строка → ±0,1 с → «Сохранить», убедись, что строка подсвечивается в нужный момент.
3. Повтори на Enhanced LRC и убедись, что слова остались на правильном относительном расстоянии.
4. Отмени правку и убедись, что текст не изменился.
5. Проверь «Авто: вкл/выкл», ручной TXT, аккорды, A–B, MIDI и мини-плеер после обновления APK поверх установленной версии.
