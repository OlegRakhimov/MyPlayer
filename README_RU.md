# Мой плеер — Android 1.1.0 (обновление)

Личный проигрыватель аудио и видео на Kotlin + Jetpack Compose + Media3. Нет рекламы, аккаунтов, аналитики, обязательного интернета, платных API. Исходный проект без сторонних рекламных SDK.

## Что изменено в 1.1.0

1. **Плейлисты:** при нажатии `+` без названия приложение выводит «Введи название», проверяет дубликаты, автоматически открывает только что созданный плейлист. Внутри него можно нажать «Добавить» и выбрать песни.
2. **Полноэкранный проигрыватель:** при выборе файла из списка открывается экран «Сейчас играет». Для MP3 показывает встроенную обложку (если есть), для видео — видео; кнопка «Текст песни» показывает прикреплённый текст. Можно переключаться между обложкой и текстом, закрывать экран, продолжать воспроизведение, менять скорость, перематывать и управлять очередью. Повторно открыть экран можно нажатием на название песни или значок расширения в мини-плеере.
3. **Караоке:** поддерживает TXT (простой текст), обычный LRC (синхронизация строк), Enhanced LRC (подсветка текущего слова). При обычном TXT/строчном LRC приложение не придумывает времена слов; для них нужны реальные метки времени.
4. **Поиск файлов на телефоне:** при первом запуске новой версии запрашивает разрешение только на чтение музыки и видео в Android MediaStore. После разрешения автоматически добавляет найденные музыкальные и видеофайлы в библиотеку. Есть кнопка «Найти музыку и видео на телефоне» для повторного сканирования, плюс прежние кнопки «Добавить файлы» и «Папка». При отказе в доступе ручной выбор файлов сохраняется.
5. **Экранные отступы:** добавлено пространство под системную строку состояния и навигацию Android.
6. **Сохранение:** пакет приложения (`com.example.freelocalplayer`) и существующее хранилище (`local_library_v1`) сохранены. Прежние записи, тексты, плейлисты и настройки не очищаются. Для MediaStore и MediaDocuments добавлена защита от части дублирующихся ссылок на одну запись.

## Как пользоваться текстами песен

Во вкладке «Тексты» выберите файл и нажмите `TXT / LRC` для импорта или `Изменить`, чтобы вставить текст вручную. При воспроизведении полноэкранный режим автоматически предлагает текст, если он прикреплён к песне.

Простой LRC (подсветка целой строки):

```lrc
[00:02.00]My life, my rules
[00:04.10]I call my own shots
```

Enhanced LRC (подсветка текущих слов):

```lrc
[00:02.00]<00:02.00>My <00:02.35>life, <00:02.70>my <00:03.00>rules
```

Времена в примерах демонстрационные и **не соответствуют автоматически какой-либо песне**. Для настоящего караоке требуется файл с размеченными временными метками. Автоматического распознавания звучащих слов нейросетью в этой версии нет.

## Как обновить существующее приложение — Windows

1. Сохраните нынешнее приложение на телефоне. **Не удаляйте его перед обновлением**, чтобы не потерять данные.
2. Распакуйте новый `FreeLocalPlayer_Android_v1.1_Source.zip` в отдельную папку, например `C:\Users\Oleg\AndroidStudioProjects\FreeLocalPlayer-1.1`. Не смешивайте файлы старого и нового исходного проекта.
3. Проверьте Android Studio, Java 17+ (рекомендуется 21), SDK Platform 36 и Android SDK Platform-Tools.
4. Запустите `Собрать_APK.cmd` либо выполните в PowerShell из папки проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

5. После успешной сборки файл лежит в `app\build\outputs\apk\debug\app-debug.apk`. Установите поверх существующего приложения без удаления старого:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Install
```

6. В Android разрешите доступ к музыке и видео. Нажмите «Найти музыку и видео на телефоне», если каталог не заполнился автоматически. Android показывает только те файлы, которые доступны через MediaStore и предоставленные разрешения; отдельные папки можно добавить через системный выбор.

**Важно про подпись APK:** при обновлении Android требует тот же ключ подписи. Если увидите `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, **не удаляйте** установленное приложение: передайте текст ошибки, чтобы решить проблему без потери данных. Сборка debug на том же компьютере обычно использует прежний ключ, но это зависит от конфигурации.

## Ограничения и проверка

- Android SDK и необходимые зависимости для полноценной сборки в среде подготовки проекта отсутствуют, поэтому **APK и тесты Compose/Media3 здесь не собраны и не проверены на устройстве**. Выполнена компиляция независимой Kotlin-логики и проверка основных сценариев парсера.
- «Обложка» берётся только из встроенного изображения медиафайла. Если в MP3 обложка не записана, будет значок музыки. Подгрузки из сети нет.
- Поиск через MediaStore зависит от разрешений и индексации Android; он не читает личные каталоги других приложений и не нарушает системные ограничения. Файлы в неудоступных каталогах следует выбрать вручную.
- При повторном сканировании удалённый только из медиатеки, но оставшийся на телефоне файл может появиться снова. Исходный файл приложение не удаляет.
- Улучшенная подсветка слов работает **только** с Enhanced LRC и точными метками. Голосовой ИИ-выравниватель пока не интегрирован.
- Устройство может не поддерживать некоторые кодеки AVI/MKV, даже если MediaStore их перечислил.
- В приложение не добавлялись музыкальные ИИ-модели распознавания гармонии/нот: это отдельное расширение, требующее оценки ресурсов и лицензий.

## Исходники и настройки

- `app/src/main/java/com/example/freelocalplayer/MainActivity.kt` — подключение, разрешения, импорт, сканирование.
- `.../media/DeviceMediaScanner.kt` — поиск через MediaStore.
- `.../media/ArtworkReader.kt` — чтение встроенной обложки.
- `.../ui/PlayerApp.kt` — библиотека, плейлисты, мини-плеер и текстовый редактор.
- `.../ui/NowPlayingScreen.kt` — полноэкранный плеер, видео, обложка, подсветка.
- `.../lyrics/LrcParser.kt` — LRC и Enhanced LRC.
- `app/src/test/...` — тесты модели медиатеки и синхронизации текстов.

Сохранились: compileSdk 36, targetSdk 36, minSdk 26, Kotlin 2.2.21, Compose BOM 2025.12.00, Media3 1.10.1, AGP 8.11.1 и Gradle 8.14.
